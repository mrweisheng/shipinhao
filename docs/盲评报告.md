# 盲评报告：模板池 vs 案例库生成（第一轮）

日期：2026-10-25｜样本：30 条真实评论｜方式：X/Y 盲评，评审不知道哪边是模板

## 一、方法

- A（模板）：从现有模板池里选一条对应场景的回复。
- B（案例）：先判意图 → 同意图检索 2–3 条相似案例 → 结合 `业务事实.md` 生成 3 个候选 → 选 1 条。
- 评审：把 A/B 随机打乱成 X/Y，按 5 个维度各打 1–5 分，再选胜者。
- 维度：是否回答问题、事实依据、语气、合规、自然度。

## 二、结果

| 指标 | 模板 A | 案例 B |
|---|---|---|
| 胜出 | 2 | **16** |
| 平手 | 12 | 12 |
| 回答问题（均分） | 3.33 | **4.13** |
| 事实依据（均分） | 4.27 | **4.57** |
| 语气（均分） | 3.87 | **4.00** |
| 合规（均分） | 4.80 | **4.90** |
| 自然度（均分） | 3.97 | **4.03** |

- 不算平手：B 胜 16/18 = **89%**。
- 算平手：B 不败 28/30 = **93%**。
- 模板只在 2 条胜出：一条是纯支持（B 过度保守不回），一条是纯捧场（B 硬加购车引导）。

## 三、案例 B 赢在哪

### 1. 复合问题，模板只答一半

| 评论 | 模板 A | 案例 B |
|---|---|---|
| 订购白色埃尔法，怎样联系提车 | `有，白色可以傾 🙏` | `白色有得傾；點頭像👤私訊我 📩` |
| 真的3万8吗？在哪里 | `3萬8，明碼實價 😄` | `係3萬8；皇后山，導航搜明哥中港牌 😄` |
| 全款吗还有什么费用吗 | `可以全款，都可以分期 😄` | `可以全款，都可以分期；費用私訊傾 📩` |
| 想换车，旧车怎么处理 | `賣車都啱傾 😄` | `換車可以傾；舊車點處理，私訊講 📩` |

### 2. 未知事实，模板会空泛带过或答错

| 评论 | 模板 A | 案例 B |
|---|---|---|
| 可以开去澳门吗 | `（不回）` | `幫你確認下，私訊傾 📩` |
| 能过户去大陆吗 | `（不回）` | `過戶嘅嘢要確認，私訊傾 📩` |
| 日本水货沃尔沃XC90多少钱 | `價錢公道，有得傾 😄` | `呢款幫你確認，私訊傾 📩` |
| 有内地车牌几钱 | `兩地牌價錢，有得傾 😄` | `要睇車型同資格，私訊幫你確認 📩` |

### 3. 先回答“是不是”，再延伸

- 评论：「你是不是帮人办香港证件？」
- 模板：`唔設門檻，可以傾 😄`（避开了“是不是”）
- 案例：`係，可以傾；唔設門檻 😄`（先答“是”，再补充）

### 4. 捧场/闲聊能接住

- 「明哥衣品，视频内搭是什么品牌」
- 模板：`多謝讚賞 🙏`（没答品牌）
- 案例：`哈哈，普通嘢，著得舒服 😄`（自然带过，不硬销）

## 四、案例 B 输在哪（要修的）

### 1. 纯捧场硬加引导

- 评论：「关注这么久，以后买车一定找明哥」
- 案例：`多謝支持；買車點頭像私訊 📩`
- 问题：对方只是表忠，立刻加购车引导，显得硬销。
- 修正：**纯捧场不加引导**；只有业务问题/明确求联系才引导。

### 2. 纯支持被过度判成“地域对比”

- 评论：「正常香港或文明地方做生意既态度。支持你」
- 案例：`（不回）`
- 问题：过度保守，对方是支持，不是引战。
- 修正：**先看主语和意图**；没有明确踩内地/引战，不要因为出现“香港/文明”就跳过。

### 3. 模板也答得不好的：包牌

- 评论：「包牌吗？」
- A/B 都是：`包咩細節，私訊傾 📩`
- 按你的口径“不说明细、让他找我们”，这是有意为之；但评审仍觉得没正面回答“包不包”。
- 建议：至少给一个**方向性回答**：`包牌稅險嘅嘢，私訊傾清楚 📩`（仍然不说明细，但承认在问什么）。

### 4. 做工证没有正面确认

- 评论：「有帮办过去香港做工证是吗？」
- A/B 都是：`過去做工都啱傾 😄`
- 问题：没回答“是不是帮办”。
- 修正：`係，可以幫你了解；私訊傾 📩`（先答“是”，不承诺结果）。

## 五、结论

1. **案例库 + 事实 + 生成的路线有效**，尤其在复合问题、未知事实、业务错配上，明显优于模板。
2. 但**不是无脑生成**：需要评审层拦三类问题——
   - 纯捧场硬加引导；
   - 过度保守把支持判成引战；
   - 是/否问题没有正面回答。
3. 下一轮要加“评审规则”再跑一次，重点看这三类是否被修掉。
4. 这轮是 30 条、单一模型评审，不是人工盲评；结论是“方向验证”，不是最终定论。
