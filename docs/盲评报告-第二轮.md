# 盲评报告（第二轮）：业务未知事实不再“帮你确认”

日期：2026-10-25｜同一批 30 条评论｜同一套 A/B 盲评

## 一、这一轮改了什么

上一轮案例生成在“未知事实”上会说：

> `幫你確認下，私訊傾 📩`

新的口径：

> **业务相关，但事实没列明 → 不解释、不确认，直接自信承接并引私域。**
>
> `呢個私訊我，幫你睇清楚 📩` / `詳細情況私訊傾 📩`
>
> 只有完全不相关、敏感/引战、纯表情/纯负面才不回。

同时加了三条评审规则：

- 纯捧场不加引导；
- 是/否问题先给明确答案；
- `唔設門檻` 是核准口径，不算承诺；但不得写“一定批/包批”。

## 二、结果对比

| 指标 | 第一轮 B | 第二轮 B |
|---|---|---|
| 胜出 | 16 | **24** |
| 平手 | 12 | 5 |
| 模板 A 胜 | 2 | 1 |
| 回答问题均分 | 4.13 | **4.40** |
| 事实依据均分 | 4.57 | 3.93 |
| 语气均分 | 4.00 | **4.07** |
| 合规均分 | 4.90 | 4.87 |
| 自然度均分 | 4.03 | **4.40** |

- 不算平手：B 胜 **24/25 = 96%**
- 算平手：B 不败 **29/30 = 97%**

事实依据分从 4.57 降到 3.93，主要不是内容变差，而是评审把 `唔設門檻 / 學歷唔設限` 当成“绝对化承诺”扣了分。按你的口径，这是核准说法，不是承诺；下一轮评审规则要明确区分“不设门槛”和“包批/一定得”。

## 四、还剩下的问题

1. **`唔設門檻` 被评审误判为绝对化承诺**
   - 这是口径问题，不是文案问题。
   - 下一轮评审明确：`唔設門檻` = 核准说法；`一定批 / 包批 / 保證` = 违规。

2. **模板 A 唯一胜出：e29**
   - A：`哈哈，承你貴言 🙏`
   - B：`承你貴言，繼續努力 🙏`
   - 差在“哈哈”更自然；以后给纯捧场保留口语前缀。

3. **包牌问题仍然没有直接 yes/no**
   - 按“不说明细”的口径，`包唔包牌，私訊傾最清楚` 是可接受的；
   - 但评审仍觉得没正面回答。下一轮可以讨论：是否允许一句方向性回答（例如“包牌稅險要睇方案”）。

4. **事实依据分被评审口径拉低**
   - 需要把“公司核准口径”和“模型编造事实”分开评分；
   - 否则 B 会因为遵守业务规则反而被扣分。

## 五、结论

- 新规则有效：B 从 16 胜提升到 **24 胜**，不算平手 **96%**。
- “未知业务事实 → 自信承接 + 引私域”比“帮你确认”明显更像专业销售。
- 下一轮重点不是改文案，而是**修评审口径**：区分“不设门槛”与“承诺”、区分“核准口径”与“编造事实”。
- 仍然是 30 条、单一模型评审；建议第三轮加人工抽检 10 条，再考虑接入正式发送。
