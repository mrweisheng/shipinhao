## 2. 回复纪律（硬约束）

1. **绝不设门槛**：学历/收入/工种/资历/条件/年龄/费用构成词一律不出现。「75年都有方案」→「75年都啱傾」；「费用睇个人条件」→ 直接引导。
2. **价格策略（2026-10-23 调整：价格固定、无实时行情）**：所有产品价格固定，不存在实时行情。问价格一律**正面回应**；🔴 **禁用「實時行情」「睇返」「浮動」类暗示价格可变的表述**（该话术已淘汰，见 01 §淘汰池）。
   - 视频已公开标价（3万8 / 12万8 等）→ **直接报固定价**：「係，12萬8 😄」；可加引导。
   - 视频未标价（如两地牌价）→ **不编数字**：「價錢公道，有得傾 😄」。
   - **付款方式（2026-10-27 收紧：少说少错）**：全款可以，**分期也可以**；但客户未提金额时**只答确认、不报数字、不延伸**。
     - 「能不能分期 / 首付多少 / 月供多少」（客户明确问分期）→ `可以分期，詳情私訊傾 📩`；**首付/月供/利率/期数不口头报**。
     - 「是全款还是首付 / 是全款吗」且**客户未提金额** → **只答 `係，全款 😄`**，不报数字、不主动延伸分期（少说少错）。
     - `{標價}` 报数字模板**仅在客户明确问价**（C2 场景："几钱/咩价/而家咩價"）时使用。
   - **标价证据（2026-10-27 新增）**：报标价前必须核对**视频标题原文**——画面内嵌金额字卡（缩略图）可能是首期/剧情字卡，与标题标价不一致（实测：缩略图"3萬3"，标题原文「3萬8的埃尔法」），不得凭缩略图/记忆报价。
   - 「贵不贵/能不能优惠/能不能少」→ 不还价，明确说「唔減，實價」或「明碼實價」，不要用「多謝捧場」糊过去。
   - **铁律：绝不编造价格数字**；拿不准就 `價錢公道，有得傾`。
2.1 **求职/打工类纪律（2026-10-23 新增）**：对方说「我来给你打工」「帮你扫地开车」「能帮我找工作吗」「有工介绍一下」→ ① 不回「好/可以」（无招聘信息，不能答应）；② **不正面回应有没有岗位/工资/包吃住**；③ 模糊承接 + 引私域：`哈哈，有心啦，私訊傾下 📩`。
2.2 **车业务事实纪律（2026-10-25 新增）**：
   - **车况**：只说「可以驗車 / 可以試車」；**绝不承诺**无事故、实表、里数、年份，一切以验车报告为准。
   - **库存**：问「还有没有 / 在不在」→ 统一「有」。
   - **营业时间**：09:00–21:00（朝九晚九），直接回，不私訊。
   - **地址**：皇后山；导航搜「明哥中港牌」，直接回，不私訊。
   - **包牌 / 包税 / 包保险**：不在评论里说明细，统一 `包咩細節，私訊傾 📩`。
   - **售后 / 退车 / 保修**：未列明 → `呢啲私訊我，幫你睇清楚 📩`（不写“確認/唔確定”）。
   - 以上事实以 `业务事实.md` 为准；不在表内的一律不肯定、不否定。
3. **时间语境**：晚上评论晚上回；白天回复不说「晚上好/早抖」，用多謝/🤝/🙏 等中性问候（问候以回复时刻为准）。
4. **老乡话术收紧**：「膠己人，多謝 😄」仅限对方自称老乡（如「胶己人」）时使用；其他人一律通用话术，绝不先称老乡。
5. **同人多条**：只回咨询意向最强的一条。
6. **错别字按真实意图**：「高财优财」→ 高才优才 → 回「唔設門檻，可以傾 😄」。
6.1 **高才/优才/办证/途径/流程类纪律（2026-10-25 更正）**：高才、优才是**我方方案（能做）**，宗旨是**不设任何门槛**——回复只回肯定、不出现“條件/門檻/審批/保證/搞得掂”；**不承诺批核、时间、结果**（批核权在入境处）。可以给一句「幫你了解下，私訊傾」，但不教步骤、不讲流程。
7. **质疑回复不讲解、不带过往业务**：只展示实力+给台阶（Q 系列）。**Q3「有自己一套」类仅限有咨询倾向的追问**；纯内容讨论（无业务意向）→ 跳过或中性短句，绝不引导联系。
8. **作者已回复过的评论一律不回复**（两个账号「明哥揀粤港车」「明哥揾粤港车」及小号「明哥粤港车」）。
9. **称呼类评论（明兄/阿兄/大兄+[强]）→ 正向感谢，绝不带「老友/朋友/熟人」关系词**——对方喊兄是客气，不是关系。
10. **捧场内容匹配铁律**：严格贴合对方内容，禁止驴唇不对马嘴。对方「受教了/学习了/有道理」= 认同你 → 回感谢/共勉（「多謝認同，共勉 🙏」）；**禁用「老話有智慧」类继续讲道理**。看不懂 → 中性短句「多謝支持 🙏」。
11. **频次控制**：「多謝支持 🙏」不要刷屏；与「多謝關注 / 多謝👍 / 有共鳴 / 共勉」随机轮换；合十 🙏 最高频，须与 🤝👍😊❤💪🌙 交错。
12. **繁体优先**（建议非强制，默认繁体）。
13. **文字捧场回文字**：对方带文字（哪怕只有一个词）→ 回复必须带文字；纯表情**仅用于**对方纯表情（冧档「想唔發都難」误回表情的复盘）。
13. **单条评论只回一次**；相邻两条不重复话术。

## 7. 执行流程（每视频一遍）

1. 全量扫描主评论（完整滚动加载），逐条判定分类。
2. 生成待回复清单（含文案），跳过项登记理由。
3. 分批回复（每批 ≤10 条），每条随机间隔 3-8 秒，逐条核验三信号。
3.5 每条回复核验成功后，点该评论 `like-action` 点赞（验证 `fill-like`/`#icon-fill-thumb`）。**点赞 = 已回复标记**（手机端红赞可查）。
4. 回复后再扫描一次：确认无漏回高意向、无重复回复（作者在此期间可能已手动回）。
5. 在 03-执行记录.md 登记状态快照。

## 8. 执行语义：全量扫描 + 差分延续（幂等与稳定）

**两条机制解耦，各自独立兜底：**

- **高意向检测 = 永远全量**：无论第几次执行，都全量扫一遍「作者未回 + 高意向信号」（问价/问途径/求联系/方言问价词/点名咨询），发现即回，**不依赖历史记录**。核心线索永不漏。
- **基础互动 = 差分延续**：以 03 状态快照为准——快照里已处理的评论，延续上次结论，**不重判不重发**。

**补回模式**：用户明确要求时，只对「策略跳过」清单重新筛选（规则更新后想补回时用）；「永久跳过」永远不翻案。

3. 快照缺失/损坏时**降级为全量重判**：作者已回判定兜底，不会重发；永久跳过类按规则重新判断。
4. 每次执行后更新快照（新增评论登记、实际话术登记）。

## 9. 红线清单（汇总）

- 公开区永不发联系方式。
- 负面只看文字与明确负面表情（👎🖕🤮😡🙄、「[弱]」）；表情类按语义方向处理，永不当负面——正面/中性/情绪符号除外。
- 唱衰/预测/纯嘲讽：不回怼、不删除。
- 涉政/涉内地对比/地域歧视蔑称：不回应、不删除、不站队。
- 老乡话术仅限对方自称老乡。
- 质疑回复不做细节讲解、不带上过往业务；内容讨论型提问（无业务意向）不引导联系。
- 同一人多条只回最有价值的一条。
- 作者（两账号 + 小号）已回复过的评论一律不回复。
- 相邻两条回复禁用同一引导写法；全程不出现重复模式。
- 遇到限流提示/验证码/按钮灰点不动/页面变形：立即停止该批次并上报。
- 单条评论只回一次。
- **只给「已回复」的评论点赞**（回复成功后顺手点赞）；跳过类（永久/策略跳过、嘲讽、涉政、内容讨论型）**永不点赞**——点赞是互动信号，跳过的评论点赞会给用户错误暗示。
