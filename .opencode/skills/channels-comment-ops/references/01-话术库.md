# 01 话术库（回复文案唯一来源）

所有回复文案从本文件选择；相邻两条不重复；繁体优先。文案 ≤20 字（引导类）。

> **业务事实以 `业务事实.md` 为准**：分期可以；车况只说可验车/试车；在不在统一“有”；
> 营业时间朝九晚九、地址正常回；包牌税险不说明细、引私讯；高才优才不设门槛；
> 求职无招聘信息。业务相关但事实不在表内 → `呢個私訊我，幫你睇清楚 📩`，不写“確認/唔確定”。

> 批量维护时由**模型按语义**判断与起草（`12-prepare-plan.js` → 填 plan → `13-execute-plan.js`）；
> `模板池.md` 是语料参考，不是「关键词 → 模板」的映射表。脚本不含业务关键词。

## 引导纪律（2026-10-24 恢复 + 扩充）

**继续用「點頭像 / 睇簡介 / 私訊 / 置頂」这一套。** 它转化效率最高，对方知道怎么联系。
已知这类回复有概率“仅作者可见”，作者端查不出来；接受这个概率，不因个案停用。

| 项 | 规则 |
|---|---|
| 变体 | 尽量丰富；同一种写法相邻不重复；一条回复只走一条路径（头像→简介→私讯 / 头像→私讯 / 私讯 / 置顶） |
| 长度 | 含标点 ≤22 字（尽量 ≤20） |
| 表情 | 每条至少 1 个；👤🔍📩💬🙏 轮换 |
| 仍禁止 | 微信、VX、wechat、電話、手機、加我、二維碼、號碼、聯繫方式、聯絡方式、唔方便喺度講、私下講 |
| 简体 | 「私信」一律写繁体「私訊」 |
| 被吞 | 只登记，不删、不重发（用户 2026-10-24 口径） |

**完整变体池（155 条）见 `模板池.md` 的 `GUIDE-*` 分组**：
`GUIDE-FULL`（头像→简介→私讯）、`GUIDE-SHORT`（头像→私讯）、`GUIDE-BIO`（头像→简介）、
`GUIDE-DM`（私讯为主）、`GUIDE-SYMBOL`（点号/符号变形）、`GUIDE-TALK`（口语）、`GUIDE-PIN`（置顶）、`GUIDE-HOME`（主页）。

## Q 系列：质疑（就事论事）轻回

- Q1 对实力质疑：「明哥唔會攞名聲開玩笑，有疑問可以先了解下再講 🙏」
- Q2 对身份/资格质疑：「明哥當然係 OK 嘅，穩穩陣陣 😊」
- Q2b：「梗係冇問題，實力擺喺度 👍」
- **Q3 深度追问（有咨询倾向时才用）**：「明哥有自己嘅一套，傾過你就知；點.頭像👤搵我慢慢傾 😄」——**仅限对方有业务咨询倾向**（问做法但带着想办的信号）。
- **内容讨论型提问（无业务意向）**：针对视频内容追问（「如果真係咁你點解決」「結果係點」），无问价/问途径/求联系信号 → **默认不回复**；小视频（评论总数 ≤20）想多互动可轻回**中性短句（绝不带引导）**：「哈哈，有自己一套 😄」「穩穩陣陣 😊」「有晒方案嘅 😄」。
- 质疑升级（脏字/骗子指控/人身攻击/纯嘲讽）→ 不回不删。

## 价格与付款话术（2026-10-25 更正）

- 视频已公开标价（「12万8宾利」「3万8埃尔法」等）→ **正面报固定价** + 引导：
  - 问「现在什么价」→「{標價}，明碼實價；點.頭像搵明哥 😄」（C2）
  - 问「是全款吗/是首付吗」（客户未提金额）→ 只答「係，全款 😄」（C14，**不报数字、不延伸分期——少说少错**）
  - 问「能不能分期 / 首付多少 / 月供多少」→「可以分期，詳情私訊傾 📩」；首付/月供/利率/期数**不口头报**
- 视频未标价（两地牌等）→ **不编数字**，正面引导：「有得傾，價錢公道；頭像私訊傾下具體 🙏」（C2b）
- 「太贵了/能不能优惠」→ 不还价，明确「唔減，實價」或「明碼實價」；不要用「多謝捧場」糊过去。
- 🔴 **禁用「實時行情」「睇返」「浮動」类表述**（曾用「實時行情要睇返；頭像 私訊傾下具體」回复绝世好爸——错误暗示行情可变，已淘汰登记，见下节）。
- 🔴 **绝不编造价格数字**；标价未知 → 一律用 C2b 引导联系。
