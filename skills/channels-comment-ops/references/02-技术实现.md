# 02 技术实现（执行前必读）

站点：视频号助手 `https://channels.weixin.qq.com/platform/interaction/comment`（登录为微信扫码，浏览器保持登录态）。所有页面交互经 `computer_use_tool(plane="bu")` + `import aha_browser_use as bu`。

## 0. 站点入口与误区分辨

- 评论维护唯一入口：**互动管理 → 评论**（`/platform/interaction/comment`），逐视频查看评论。
- **左侧视频列表（2026-10-23 复核）**：默认**发布时间降序**、**无置顶机制**（与抖音不同，抖音是置顶3+降序）——「最新 N 条」= 列表前 N 条；卡片含标题（完整原文）、发布时间（`YYYY/MM/DD HH:mm`）、评论数（数字字段），列表容器 `.scroll-list`，滚动容器 `.scroll-list__wrp`/`.feeds-container`（懒加载，滚动后条目数增长属正常）。
- 左下角「消息」图标（铃铛，`/platform/notification/notificationList`）= **系统通知中心**（视频获推荐、违规提醒、资质待办、直播安全等），**不含任何评论通知**——新产生的评论不会出现在那里，已核实，无需再点开。
- 评论权限 / 写评论入口在右侧列表顶部（评论权限、写评论按钮），不属于维护范围。

## 0.6 登录态检查与账号切换（固定流程）

- 打开管理后台（`/platform`）**第一步：判定登录态**：
  - 已登录：页面显示管理后台内容（左侧菜单 / 互动管理入口可见）→ 直接继续任务。
  - 未登录：显示微信扫码登录页 → `interaction.request_action(type="browserControl")` 提示用户扫码；扫码完成交回后重新观察页面再操作。
- 用户明确说「切换新账号」：
  1. 先观察当前是否登录态。
  2. 已登录 → 找退出入口（右上角头像/账号菜单 → 退出登录/退出当前账号），点击退出，等页面回到扫码状态。
  3. 若打开即扫码态 → **无需退出操作**，直接进入第 4 步。
  4. `interaction.request_action` 提示用户扫码新账号；扫码完成后重新观察，确认登录账号变为新账号（页头账号名）再继续。
- 退出后登录态清除，旧 ref 全部失效，必须重新观察页面。

## 0.7 页面结构自适应（布局变化自动更新，无需人工）

- 每次执行第一步固定跑 §0.5 探针（两级命中标准），**命中即直接按快照执行，不重复探查、不反复尝试**。
- 探针 miss（任一关键选择器为 0）→ 布局已变 → 跑自适应 dump 拿新类名 → **把新选择器回写 §0.5 表格与 §6 选择器速查（注明发现日期）→ 用新结构继续执行**。回写即自动更新，下次执行直接用新快照。
- dump 也拿不到结构（页面严重变化/未登录/网络异常）→ **停止并上报用户**，不做无效重试。

## 1. 关键结构事实（已实测）

- 评论区内容在 **wujie 微前端 Shadow DOM** 内：宿主 `document.querySelector('wujie-app.wujie_iframe, [class*="wujie_iframe"]')` → `.shadowRoot`，一切在其中查询。
- **`bu.find` 对 Shadow DOM 无效**（返回 0 匹配），一律用 `bu.js` 穿透 shadowRoot 操作。
- 输入框是 **Vue 受控组件**：手动改 value 不点亮发送按钮，必须真实键盘输入（`bu.type`）。
- 主评论 vs 回复区分：`item.closest('.comment-reply-list')` 存在则为回复，跳过。
- 定位主评论唯一键：评论时间 `.comment-time`（格式 `YYYY/MM/DD HH:mm`）；同时间戳多条按 DOM 序号区分。
- active 判定须 `cl.split(' ').includes('active-feed')`（substring 会误伤 inactive-feed，已踩坑）。
- 滚动容器 `.feed-comment__wrp`：循环设 `scrollTop = scrollHeight`，连续 3 次不变判稳。

## 2. 全量扫描（复制进 computer_use_tool cell 使用）

```python
import aha_browser_use as bu
import json, time

# 滚动加载到底（连续3次scrollTop不变停止）
prev = -1; stable = 0
for i in range(30):
    r = bu.js("(() => { const h = document.querySelector('wujie-app.wujie_iframe, [class*=\"wujie_iframe\"]').shadowRoot; const b = h.querySelector('.feed-comment__wrp'); b.scrollTop = b.scrollHeight; return b.scrollTop + '/' + b.scrollHeight; })()")
    parts = r.split('/')
    if len(parts) == 2:
        cur = float(parts[0])
        if cur == prev: stable += 1
        else: stable = 0
        if stable >= 3: break
        prev = cur
    time.sleep(1.2)

# 扫描全部主评论
js = r"""
(() => {
  const host = document.querySelector('wujie-app.wujie_iframe, [class*="wujie_iframe"]');
  const root = host.shadowRoot;
  const box = root.querySelector('.feed-comment__wrp');
  const items = box.querySelectorAll('.comment-item');
  const rows = [];
  for (const item of items) {
    if (item.closest('.comment-reply-list')) continue;
    const name = item.querySelector('.comment-user-name')?.innerText?.trim() || '';
    const time = item.querySelector('.comment-time')?.innerText?.trim() || '';
    const content = item.querySelector('.comment-content')?.innerText?.trim() || '';
    const emojis = Array.from(item.querySelectorAll('.comment-content img.we-emoji')).map(i => i.alt);
    const replyNames = Array.from(item.querySelectorAll('.comment-reply-list .comment-item')).map(r => r.querySelector('.comment-user-name')?.innerText?.trim() || '');
    const authorReplied = replyNames.some(r => r === '明哥揀粤港车' || r === '明哥揾粤港车' || r === '明哥粤港车');
    rows.push({time, name, content, emojis, authorReplied});
  }
  return JSON.stringify(rows);
})()
"""
rows = json.loads(bu.js(js))
print("主评论总数:", len(rows))
for i, r in enumerate(rows, 1):
    c = r["content"] or ("[" + "".join(r["emojis"]) + "]")
    print(f"{i:03d} | {r['time']} | {r['name'][:10]} | {c[:38]} | 作者回:{r['authorReplied']}")
```

## 3. 回复一条评论（核心模板）

```python
import aha_browser_use as bu
import time, re, random

def open_panel(ts):
    js = f"""
    (() => {{
      const host = document.querySelector('wujie-app.wujie_iframe, [class*="wujie_iframe"]');
      const root = host.shadowRoot;
      const box = root.querySelector('.feed-comment__wrp');
      const items = box.querySelectorAll('.comment-item');
      for (const item of items) {{
        if (item.closest('.comment-reply-list')) continue;
        const t = item.querySelector('.comment-time')?.innerText?.trim() || '';
        if (t !== '{ts}') continue;
        const replies = Array.from(item.querySelectorAll('.comment-reply-list .comment-item')).map(r => r.querySelector('.comment-user-name')?.innerText?.trim() || '');
        if (replies.some(r => r === '明哥揀粤港车' || r === '明哥揾粤港车' || r === '明哥粤港车')) continue;  # 作者（两账号+小号）已回跳过
        item.scrollIntoView({{block: 'center'}});
        const btn = item.querySelector('.action-icon.weui-icon-outlined-comment');
        if (!btn) return 'NO_BTN';
        btn.click();
        return 'OPENED';
      }}
      return 'NOT_FOUND';
    }})()
    """
    return bu.js(js)

def check_and_send():
    js = r"""
    (() => {
      const host = document.querySelector('wujie-app.wujie_iframe, [class*="wujie_iframe"]');
      const root = host.shadowRoot;
      const ta = root.querySelector('textarea.create-input');
      if (!ta) return 'NO_TEXTAREA';
      const btns = ta.closest('.comment-item').querySelectorAll('.create-ft .tag-wrap');
      for (const b of btns) { if (b.className.includes('primary')) { b.click(); return 'SENT'; } }
      return 'NOT_PRIMARY';
    })()
    """
    return bu.js(js)

# 回复流程（对每条目标评论，置于 for 循环内）
print(open_panel("2026/10/17 14:31"))          # 目标时间戳
time.sleep(1.2)
snap = bu.snapshot(within="viewport", view="interactive", max_chars=2500)
m = re.search(r'(\w+)\s+textbox "回复 ([^"]+)："', str(snap))   # 核对面板对象昵称
if not m:
    print("NO_TEXTAREA_REF")      # 未捕获到输入框，本条约过，在 for 循环中 continue
else:
    bu.type(m.group(1), "多謝認同 🙏", submit=False)   # 真实键盘输入
    time.sleep(0.8)
    print(check_and_send())
    time.sleep(3)                                     # 等发送生效
    print(verify(ts))                                 # 三信号核验（见§4）
    time.sleep(random.uniform(3, 8))                  # 随机间隔，防风控
```

## 4. 三信号核验

```python
def verify(ts):
    js = f"""
    (() => {{
      const host = document.querySelector('wujie-app.wujie_iframe, [class*="wujie_iframe"]');
      const root = host.shadowRoot;
      const tips = root.querySelector('.comment-count__tips')?.innerText || '';
      const taCount = root.querySelectorAll('textarea.create-input').length;
      const box = root.querySelector('.feed-comment__wrp');
      let found = null;
      for (const item of box.querySelectorAll('.comment-item')) {{
        if (item.closest('.comment-reply-list')) continue;
        const t = item.querySelector('.comment-time')?.innerText?.trim() || '';
        if (t === '{ts}') {{
          const reps = Array.from(item.querySelectorAll('.comment-reply-list .comment-item')).map(r => r.querySelector('.comment-content')?.innerText?.trim() || '');
          if (reps.length) {{ found = reps; break; }}
        }}
      }}
      return JSON.stringify({{tips, taCount, found}});
    }})()
    """
    return bu.js(js)
```

- 成功 = 计数 +1（`共 N 条`）且目标主评论 reply-list 出现新回复且 textarea 数 0。
- **同时间戳多条**：open 时按 DOM 序号定位（`let n=0; if (n<idx){n+=1;continue;}`），发后用「昵称+回复内容」列表精确核验归属（曾踩：11:54 两条，verify 按时间抓会抓到第一条）。

## 5. 已知异常与处理（已实测闭环）

| 异常 | 处理 |
|---|---|
| snapshot 不捕获已打开 textarea | 用 CSS locator `textarea.create-input` 兜底定位；残留输入可直接点发送按钮 |
| 发送后计数未 +1 | 先扫描核验 reply-list 是否已出现回复；未出现才重试，禁止盲目重发 |
| 面板残留文字已输入未发送 | 直接点发送按钮补发，先核对面板对象时间戳一致 |
| 工具超时中断（单批 >12 条易触发 240-300s 超时） | 每批 ≤10 条；中断后先扫描已发送计数再续跑（曾中断后确认前 9 条已发，跳过已发条目从断点继续） |
| 滚动后 DOM 节点数变化（懒加载回收） | 以最新一次完整扫描为准，滚动到底判稳后再数 |
| 同时间戳多条 | DOM 序号定位 + 发后精确核验归属 |
| 回复被吞（发出后评论区看不到） | 停用该话术/引导变体，改用防吞变体，登记到 03-执行记录.md |
| 回复「自己可见、他人看不到」（2026-10-24 实测） | 作者端重载仍可见，接口 `displayFlag=131074 / visibleFlag=0 / blacklistFlag=0` 与正常回复完全一致，**技术上无法自检**。只能用第二个账号（观察号）看同一视频抽检；命中即停用该变体、删除后换保守话术重发一次 |
| 发送后计数未 +1 且面板已关闭（SENT/CLICKED 都成功） | **必须看 `sent-*.json` 的 trace**：顶层 `errCode=0` 不代表成功，真实错误在 `data.baseResp.errcode`。`-4010` = 平台限制（页面提示“暂时无法使用该功能”）；历史 console `handleAddReply 423` 也出现过。记入永久跳过，禁止连续重试 |
| 评论区虚拟滚动，跨屏评论不在 DOM | 评论区 `.feed-comment__wrp` 只渲染视口附近节点；跨屏定位按 `scrollTop ±= clientHeight*1.2` 逐屏滚动（每屏扫一次目标） |
| 昵称带特殊前缀（如「꧁ཊ蔡丹ཏ꧂」「【A】亿德发一干果批发行」） | `startswith` 匹配失败 → 一律用 `name.includes(片段)` + 内容关键词定位 |
| 误触「删除」图标弹出删除确认框 | 回复按钮精确用 `.action-icon.weui-icon-outlined-comment`；误弹后循环点「取消」清理，绝不点「删除/替换置顶」 |
| 同一评论时间戳跨轮次不一致（实测 10:45 vs 10:33） | 回复定位以「名称+内容关键词」为锚，不依赖时间戳；同时间多条按 DOM 序处理 |
| 限流提示/验证码/按钮灰点/页面变形 | 立即停止该批次并上报用户 |

## 7. 增量维护与状态快照（幂等执行）

**执行前必读**：03-执行记录.md 中对应视频的「状态快照」块（若存在）。

**差分流程**：
1. 全量扫描（见第 2 节）→ 得到本轮全部主评论列表。
2. 读 03 该视频快照：快照里已有的评论标识（昵称@时间+内容前8字）→ 延续结论（已回复/永久跳过/策略跳过）；快照里没有的 → 新评论，按 00 分类表处理。
3. 高意向检测独立全量跑一遍：作者未回 + 高意向信号 → 必回（即使快照里有记录，只要快照标记非「已回复」且是永久类之外……高意向永不被策略跳过）。
4. 回复批次照常（第 3 节模板），逐条核验。
5. 写回快照：新增评论登记 + 实际发出话术文本（供 01 查重池）。

**评论唯一标识**：无 DOM id（已实测 data-v 仅组件标记）。用「昵称@时间戳+内容前8字」复合键；同人同时同内容冲突时按作者已回判定兜底，不重发。

**快照缺失降级**：无快照 → 全量重判（安全：作者已回判定保证不重发；永久跳过类重新按规则判断）。
## 8. 点赞（回复成功后标记）

**按钮**：目标主评论 `.comment-item .action-item.like-action`（svg use `#icon-thumb`，tooltip「点赞」，文字后第一个按钮）。

**操作**：点 `like-action` 一次。

**核验（三信号之一变即可确认）**：
- svg use 从 `#icon-thumb` → `#icon-fill-thumb`
- class 出现 `fill-like`
- 点赞计数从无 → 「1」（like-action innerText）

**纪律**：仅对「已回复」评论点赞（回复核验成功后执行）；跳过类评论永不点赞。点赞也带随机间隔（与回复同批 3-8 秒），避免连续点击触发风控。

**手机端同步（2026-10-23 实证）**：PC 后台点赞后，手机端评论区该评论显示「作者赞过」+ 红赞标记——即「点赞=已回复」的可视标记，用户手机看通知即可快速判断哪些已回，无需点进评论逐条核对。

**模板**：
```python
def like_comment(ts):
    js = f"""
    (() => {{
      const host = document.querySelector('wujie-app.wujie_iframe, [class*="wujie_iframe"]');
      const root = host.shadowRoot;
      const box = root.querySelector('.feed-comment__wrp');
      for (const item of box.querySelectorAll('.comment-item')) {{
        if (item.closest('.comment-reply-list')) continue;
        const t = item.querySelector('.comment-time')?.innerText?.trim() || '';
        if (t !== '{ts}') continue;
        const like = item.querySelector('.action-item.like-action');
        if (!like) return 'NO_LIKE_BTN';
        const use = like.querySelector('use')?.getAttribute('xlink:href');
        if (use === '#icon-fill-thumb') return 'ALREADY_LIKED';
        like.click();
        return 'LIKED';
      }}
      return 'NOT_FOUND';
    }})()
    """
    return bu.js(js)
```
返回 `LIKED`/`ALREADY_LIKED` 后 1.5s 再核验 `fill-like` 出现。`ALREADY_LIKED`/`NO_LIKE_BTN` 视为完成（已红跳过/按钮不存在），**不阻塞批次**，继续下一条。

**列表条目点击注意**（2026-10-22 实测）：左侧视频列表的标题是完整原文（如「香港真的是一个豪车超有信价比的地方，12万8就能拿下一台宾利！」），**不要用简称匹配**（「12万8宾利」会 TEXT_NOT_FOUND）。匹配用标题独有连续片段（「拿下一台宾利」「3万8的埃尔法」）。
**批量补赞流程**：扫描主评论（作者已回 + like 状态）→ 对「已回 && 未赞」逐条点赞（3-8s 间隔）→ 每条核验 fill-like；「已红」一律跳过（不管谁赞的）。
