# 01 话术库（场景化话术池）

> **定位（2026-11-02 调整）**：评论区是**口碑场**。回复主要做三件事：
> ① 感谢捧场 ② 事实回答 ③ 偶尔实力背书。
> **引导话术保留但控频**——大部分评论（≥80%）纯感谢/事实回答，不带任何引导；
> 只有客户主动求联系、或高意向咨询时，才用引导话术（点头像/主頁/搵明哥），**单批引导类占比 ≤20%**。
> **🔴 私訊两个字绝对不用**——不管繁体简体，都不出现。
>
> **铁律**：
> - 🔴 **置顶引导永久删除**：「睇🔝頂部第一條」不用——我们自己看得到置顶，客户那边可能被系统屏蔽
> - 🔴 **零数字**：不管视频标没标价，评论区一个数字都不报（跨视频串问必错）
> - 🔴 **不提"價/錢/標價/全款/首付"**任何交易词
> - 🔴 **引导词轮换**：點頭像/主頁/搵明哥，不要单出口；同一条连续不超 2 次
> - 🔴 **私訊绝对不用**：不管繁体简体，话术里不出现"私訊/私信"两个字
> - 🟢 **引导话术保留**：客户主动问"怎么联系你"时，正常指路；高意向咨询时给弱引导

所有话术 ≤20 字，至少 1 表情，相邻两条不重复，繁体优先。

## 事实回答类（直接答，不背书）

> 客户问的是客观事实，直接给答案，不加任何业务引导。
> **是/否问题先正面答**（可以／有／得／搞得掂）；低意向的「能不能」答完即止，不硬塞引导。

| 场景 | 回复（轮换） |
|---|---|
| 车还在不在/卖左未 | 有，喺度 😄 / 有嘅 👍 / 係，就係呢度 😊 |
| 问颜色/车型/现车 | 有，現場睇 👍 / 咩都有 😄 |
| 车况/公里数/事故 | 可以驗車，現場睇 😄 / 可以試車，約時間 👍 / 車況睇實車 🙏 |
| 问地址/哪里看车 | 皇后山，導航搜「明哥中港牌」😄 |
| 问营业时间/几点开门 | 朝九晚九，過嚟睇 👍 / 朝九晚九，隨時嚟 🙏 |
| 能不能试车 | 可以試車，約時間 😄 |
| 能不能过户去大陆 / 带返大陆 | 可以，明哥搞得掂 👍 / 可以，交俾明哥 😄（低意向，答完即止，不带引导） |

## 问价类（不报数、不提"價/錢"，引导到店+现车多）

> 🔴 铁律：不管视频标没标价，评论区一个数字都不报。
> 🔴 话术里不出现"價/錢/標價/全款/首付"任何交易词。
> 🔴 **核心思路（2026-11-02 升级）**：问价是高意向客户，不要冷冰冰说"我不说"。
> 直接引导到店 + 说现车多，降低客户心理门槛，邀请来看。

| 场景 | 回复（轮换） |
|---|---|
| 多少钱/什么价/几钱/果钱 | 皇后山，導航搜明哥中港牌；現車多，任你揀 😄 / 導航搜明哥中港牌，現車多 👍 / 多款現車，導航搜明哥中港牌 😄 |
| 全款还是首付 | 都可以，多謝 😄 / 靈活嘅，現車多 🙏 |
| 太贵了/能不能优惠/能不能少 | 多謝，公道嘅 🙏 / 唔減，多謝 😄 |

> 「皇后山」必须和「導航搜明哥中港牌」绑定说，不能单独说皇后山（大地名，客户不知道具体位置）。
> 「現車多」= 告诉客户选择多，不用纠结数字，到店自然谈。
> 「導航搜明哥中港牌」= 事实引导到店，不是线上引导，不算引导类占比。
> 问价类优先用"引导到店+现车多"，不用干巴巴的"唔講數"。

## 求联系类（客户主动问，正常指路，引导轮换）

> 客户明确问"怎么联系你/找你是真假/有联系方式吗"——这是最高意向，必须指路。
> 引导话术轮换使用：主頁/點頭像/搵明哥，不要单出口。

> **置顶引导（睇🔝頂部第一條）永久不用**——置顶可能被系统屏蔽。

| 场景 | 回复（轮换） |
|---|---|
| 怎么联系你/有联系方式吗 | 多謝信任！主頁見 😄 / 多謝信任！主頁搵到我 🙏 |

## 禁用词清单（2026-11-02 调整版）
